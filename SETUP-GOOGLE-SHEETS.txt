ZENOC CONTACT FORM — REPAIRED FILES

FILES
- Code.gs: replace the full contents of your Apps Script editor with this file.
- script.js: updated website form sender; the existing /exec URL is already inserted.
- index.html, capabilities.html, about.html, styles.css, zenoc-logo.png: website files.

IMPORTANT DEPLOYMENT STEPS
1. Open the Google Sheet that should receive enquiries.
2. Open Extensions > Apps Script.
3. Replace the entire Apps Script editor content with Code.gs and Save.
4. Deploy > Manage deployments > click the pencil on the ACTIVE web app.
5. Under Version choose New version. Keep Execute as = Me and Who has access = Anyone.
6. Click Deploy and authorize if Google asks. Use the Web app URL ending in /exec.
7. The existing URL is already set in script.js. If Google gives you a different URL, replace GOOGLE_SCRIPT_URL in script.js.
8. Upload all website files together, replacing the old script.js.

VERIFY THE ENDPOINT
Open the /exec URL in a browser. It should show JSON with:
  "ok": true
  "service": "ZENOC Enquiries"
  "status": "ready"
It also returns the spreadsheet URL and the Enquiries tab name.

If the script is bound to your Google Sheet, enquiries go into that spreadsheet.
If it is a standalone script and cannot find an active spreadsheet, it creates a
spreadsheet named "ZENOC Enquiries"; its URL is shown by the /exec health check.

TEST
Submit one test enquiry on the website, then refresh the Enquiries tab.
Columns: Submitted At | Name | Email | Service | Project Details

NOTE ABOUT BROWSER FEEDBACK
The website uses a no-cors request because Apps Script ContentService responses
do not provide a normal readable CORS response to a static website. The browser
cannot inspect the server response, so verify the test row in Google Sheets.
